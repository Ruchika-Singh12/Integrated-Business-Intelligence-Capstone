# 📌 Project Overview

This Capstone Project demonstrates a complete Business Intelligence and Data Analytics workflow using multiple real-world datasets. The project focuses on extracting meaningful insights through Exploratory Data Analysis (EDA), statistical analysis, machine learning, and interactive dashboards.

The project combines Sales Analysis, Customer Churn Analysis, and House Price Analysis to support data-driven business decision-making.

---

# 🎯 Objectives

- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Analyze sales performance
- Study customer churn behavior
- Analyze house price trends
- Perform statistical hypothesis testing
- Build a Linear Regression model
- Generate business insights
- Create interactive dashboards
- Produce professional visualizations

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Week8_Capstone_Project.git
```

Go to project folder

```bash
cd Week8_Capstone_Project
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python capstone_analysis.py
```
